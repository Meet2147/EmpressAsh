# Adding a story

Create a file here named `YYYY-MM-DD-short-title.md`:

```
---
title: The night the Moon card found me
date: 2026-11-02
summary: One line shown on the stories list.
---
Write the story here in Markdown. Blank lines start new paragraphs.
```

Add `draft: true` to the header to hide a story. Push to `main` and Render redeploys.
